# Wallet (کیف پول شخصی)

اپ اندروید مدیریت مالی شخصی — Kotlin + Jetpack Compose + Room.

## ساخت APK
1. همه‌ی فایل‌ها را در یک ریپازیتوری گیت‌هاب آپلود کنید (شاخه `main`).
2. تب **Actions** ← workflow به نام **Build Android APK** خودکار اجرا می‌شود (یا Run workflow بزنید).
3. بعد از پایان، از انتهای صفحه‌ی همان اجرا، فایل **wallet-debug-apk** را از بخش Artifacts دانلود کنید و APK را نصب کنید.

## نکته
دیتابیس با مهاجرت (Migration) به‌روز می‌شود و داده‌های نسخه‌ی قبلی پاک نمی‌شوند. اگر روی گوشی نسخه‌ای با کلید امضای دیگر نصب است، ابتدا خروجی CSV بگیرید.
